### ⚙️ **Atividade Recente (Requer GitHub Action)**

Para atualizar automaticamente a seção de **Atividade Recente**, siga estes passos:

#### **1. Criar Repositório de Perfil**

```bash
# O repositório deve ter o MESMO nome do seu username
# Exemplo: gustavo159753/gustavo159753
```

#### **2. Criar GitHub Action**

Crie o arquivo `.github/workflows/update-readme.yml`:

```yaml
name: Update README

on:
  schedule:
    - cron: '0 */6 * * *' # Atualiza a cada 6 horas
  workflow_dispatch: # Permite executar manualmente

jobs:
  update-readme:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Update recent activity
        uses: jamesgeorge007/github-activity-readme@master
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          COMMIT_MSG: '⚡ Atualiza atividade recente'
          MAX_LINES: 5
```

#### **3. Ativar Workflow**

1. Vá em **Settings** → **Actions** → **General**
2. Em **Workflow permissions**, marque:
   - ✅ Read and write permissions
3. Salve as alterações

#### **4. Executar Primeira Vez**

1. Vá em **Actions** → **Update README**
2. Clique em **Run workflow**
